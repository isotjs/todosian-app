Todosian is an Android todo app for Obsidian users. It manages todo lists stored as Markdown files inside your vault (or any folder you sync to your phone).

Todosian reads and writes your existing .md files directly. There is no database import, no account, and no built-in sync.

<b>How it works</b>

- Connect a folder using Android's Storage Access Framework (SAF)
- Each Markdown file becomes a category
- Todos use standard Markdown checkboxes: - [ ] and - [x]

<b>Features</b>

- Add / edit / toggle / delete todos
- Optional subtasks, and notes that stay as indented lines under their task
- Custom task statuses: open, done, or your own characters such as - [/]
- Create / rename / delete categories (files)
- Optional subfolder support; notes are listed by their relative path
- Optional support for Obsidian Tasks plugin metadata (dates, priority, recurrence), with your own markers
- Daily Focus for tasks that are due or scheduled today, plus an optional daily due reminder
- Home screen widgets: a todo list with inline toggling and a quick-add button
- Grid or list category layout, compact rows, and category / todo sorting and grouping
- Pull to refresh, and writes that keep your line endings and final newline intact
- Material 3 UI, dynamic color (Android 12+), light and dark theme
- Offline-first and privacy-focused: no network permission, no analytics

<b>Notes</b>

- Todosian modifies your Markdown files directly. Keep a reliable backup of your vault/folder.
- Todosian is independent and not affiliated with Obsidian or the Obsidian Tasks plugin.
